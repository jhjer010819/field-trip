# 현장노트

현장체험학습 신청서와 보고서를 학교 양식에 맞춰 작성하고 인쇄하는 위저드입니다.

신청서에는 학생 정보, 체험 장소와 기간, 시간별 일정, 준비물을 적습니다. 보고서에는 다녀온 내용, 배운 점, 느낀 점, 앞으로의 계획과 사진을 적습니다. 신청서를 쓴 뒤에는 같은 내용으로 보고서를 이어서 만들 수 있습니다.

문서는 브라우저 `localStorage`에만 저장됩니다. 서버로 전송되지 않고, 다른 기기와 공유되지 않습니다. 인쇄 대화상자에서 대상을 PDF로 바꾸면 파일로 남길 수 있습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:3847` 에서 열립니다.

```bash
npm run lint
npm run build
npm start
```

`npm start`는 `PORT`가 있으면 그 포트를, 없으면 3847을 사용합니다.
